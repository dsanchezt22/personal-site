# Beverage landscape portfolio

Status: accepted for implementation, 2026-10-12.

Logartis is the reference for an entrance and a landscape responding to exploration. The original tea-island artwork, content, and code are created for this portfolio.

Palette: pistachio #e8eee0, forest #18382b, paper #f7f7ef, peach #edac82, muted leaf #506454. Manrope 800 carries headings; self-hosted Inter carries body text. An illustrated opening leads through beverage projects, hardware, a developer notebook, biography, and contact. The food motif comes from real projects.

The entrance drops away on request and can be skipped or replayed. A short glass chime is opt-in. Pointer and scroll motion can be disabled. Reduced-motion visitors bypass the entrance. Essential content and links work without JavaScript.

Scope: index.html, styles.css, main.js, resume PDF, favicon, artwork/fonts, build allowlist, and verification. No backend, new runtime dependencies, course-source publication, client data, DNS changes, or new hosting platform.
