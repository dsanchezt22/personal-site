Runtime: static HTML, CSS, and a small main.js bundled by esbuild, with no runtime dependency. The drawings are generated by scripts/art at build time and inlined into dist/index.html where index.html has `<!--art:name-->` placeholders. Native dialogs hold project details. The project board drags with pointer events at 760px and wider and becomes a plain list below that. X and LinkedIn URLs are static hrefs in index.html. Without JavaScript all section text remains readable. The explicit build allowlist excludes source notes and unused artwork from deployment. The existing Cloudflare Worker and domains remain the target.

Acceptance requires dragging a card without opening it, clicking and keyboard-opening every dialog, and checking responsive layouts. See the project verification skill.
