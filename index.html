Area-scalable memory

Research · Jan 2026 – present

Python models of LLM-inference throughput, latency, and memory under competing chip memory organizations. The work is with Stanford’s Engineering Robust Systems Group (Prof. Subhasish Mitra).

04

Plate Scanner

Personal

A phone web app for logging a Stanford dining-hall plate. A top photo, then a side photo. The portion comes from the plate’s dimensions and the two camera angles.

The browser checks the frame (whole rim, blur, glare). Grok vision names each food. A lookup against USDA FoodData Central, a restaurant page, or a brand label fills in closer numbers. A row is marked as a menu match only when it really is that dish. Otherwise it stays an estimate. The client is HTML, CSS, and JavaScript, served by a Python standard-library server.

HTML, CSS, JavaScript, Python
